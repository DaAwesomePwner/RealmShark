## Wave A

### Task 1: Runs & DPS page container

**Owns:** see the file map. **Reads:** R1 §0, §1.2–§1.5, §2, §6, §7.1.

- **`RunsTab`** (enum, `tomato.gui.runs`): `FEED("feed", "Feed")`, `DUNGEONS("dungeons", "Dungeons")`, `LIVE_METER("live-meter", "Live meter")`, `RECORDINGS("recordings", "Recordings")`; `id()`, `title()`, `static RunsTab of(String id)`.
- **`RunsFocus`** (record, route payload): `RunsFocus(RunsTab tab, String dungeon)`; `dungeon` is a canonical dungeon name for the Feed's dungeon filter, else null; `static RunsFocus of(RunsTab tab)`.
- **`RunsDpsPage`** (`tomato.gui.runs`, public, `extends JPanel implements AutoCloseable`, name `runs-dps-page`): holds `CustomizableTabs("runs")` (component `runs-tabs`, preference `ui.tabs.runs`) with the four tabs in `RunsTab` order, all steady (none Analyst-only). Constructor `RunsDpsPage(RunsPage feed, JComponent liveMeter)`: Feed = `feed` unchanged; Live meter = `liveMeter`; Dungeons and Recordings = holder panels.
  - `void setContent(RunsTab tab, JComponent content)`: replaces a holder's content (Dungeons, Recordings); the tab itself is never re-added.
  - `void bring(RunsTab tab)`: `show` then `select` (explicit navigation only). `RunsTab selectedTab()`. `RunsPage feed()`. `CustomizableTabs tabs()`.
  - `void owner(RunsTab tab, RouteTarget owner)`: the target whose state is captured when that tab is in front (Feed: the `RUNS` `RunsRouteTarget`; Live meter: `DpsGUI.encounterRouteTarget()`).
  - `RouteTarget routes(RunsTab tab, RouteTarget inner)`: the wrapper (R1 §1.5). `destination`, `accepts` and `redirect` delegate to `inner`. `captureState()` returns `PageState(RunsTab tab, Object inner)` = `(selectedTab(), owner(selectedTab())?.captureState())`. `open(route)`: remember the front tab and whether `tab` was hidden, `bring(tab)`, then `inner.open(route)`; on a `RuntimeException` reselect the previous tab (re-hide `tab` if it was hidden) and rethrow. `restoreState(state)`: `bring(state.tab)` first, then `owner(state.tab).restoreState(state.inner)` when both are non-null.
  - `RouteTarget tabTarget()`: accepts `Route.to(Destination.RUNS)` with a `RunsFocus` payload and nothing else; `open` brings the tab forward; for `FEED` with a dungeon it calls the hook set by `onFeedDungeon(Consumer<String>)` (Task 12 wires it).
  - `RouteTarget liveMeterTarget(Runnable focus)`: accepts plain `Route.to(Destination.ENCOUNTER)` (no recording, visit, query or payload); `open` brings Live meter forward without changing the meter's selection and runs `focus` via `invokeLater` (the navigator selects the page after `open`).
  - `tabTarget()` and `liveMeterTarget()` capture and restore the same composite `PageState` as the wrappers: the navigator captures one target per page, so every page-10 target must.
  - `close()`: closes the feed (`RunsPage.close()`) and every tab content that is `AutoCloseable` or an `ArchiveWorkspace`, **including hidden tabs** (`tabs.contents()`); idempotent.
- **`CustomizableTabs`:** `List<Component> contents()` (every tab's component in saved order, including hidden and not-offered ones) and `tabs.putClientProperty(CustomizableTabs.class, this)` so hierarchy walkers can reach hidden contents.
- **Tests:** `RunsDpsPageTest` (tab order and names; construction never shows a hidden tab and opens on the first visible tab; `bring` shows a hidden tab; the wrapper brings its tab, captures the front tab's owner state, restores the tab first, reverts on a failed open; `tabTarget` with and without a dungeon; `liveMeterTarget` accepts only plain ENCOUNTER; `close` reaches a hidden tab's content; `ui.tabs.runs` isolated), `CustomizableTabsTest` add beside (`contents()` includes hidden and Analyst tabs in Simple mode; client property).

**Steps:** failing tests; implement; run `tomato.gui.runs.*`, `tomato.gui.kit.*`. Commit ("Add the Runs & DPS page with customizable tabs and tab-aware routes").
